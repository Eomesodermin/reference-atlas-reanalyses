| | |
|---|---|

## What this analysis does

Visualises NKG7 and DNAM/CD226 expression, runs correlation and scTenifoldKnk analyses, and maps onto the HNSCC dataset.

## Scripts

Run in numeric order from this folder. Each script sets the working directory with `here::here()`, which resolves to this folder via the `.here` marker.

| Script | Title |
|---|---|
| `R/01_Load_vis_and_subset_dataset.Rmd` | Seurat_PBMC_Multimodal_dataset_PreProcessing |
| `R/02_Visualise_NKG7_Expression.Rmd` | Seurat_PBMC_Multimodal_dataset_NKG7 |
| `R/03_DNAM_Vis_and_Correlation.Rmd` | Visualisation and correlation of DNAM-1 expression |
| `R/03_Map_with_HNSCC.Rmd` | Seurat_PBMC_Multimodal_dataset_PreProcessing |
| `R/PBMC_NK_scTenifoldKnk.R` | R script |


`Setup.R` and `Load_packages.R` hold the shared environment set-up; `Functions/` holds helper functions.

`renv.lock` pins the package versions; restore them with `renv::restore()`.

## Data

The raw and processed data are not stored in this repository. Download the data from the source above into `data/` (git-ignored) before running the scripts; processed objects are regenerated by the numbered scripts.
