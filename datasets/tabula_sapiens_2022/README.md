## What this analysis does

Preprocesses and visualises the atlas to examine expression of genes and cell types of interest across organs.

## Key finding

NKG7 and the cytotoxic programme are concentrated in NK and CD8 T cells across human tissues, with tissue-specific granzyme profiles.

*Summarised from the analysis code and plots; see the scripts for the underlying evidence.*

## Scripts

Run in numeric order from this folder. Each script sets the working directory with `here::here()`, which resolves to this folder via the `.here` marker.

| Script | Title |
|---|---|
| `scripts/01_Tabula_Sapiens_dataset_preprocessing.Rmd` | Tabula_Sapeins_dataset_preprocessing |
| `scripts/02_Tabula_Sapiens_dataset_visualisation.Rmd` | Tabula_Sapeins_dataset_analysis |


`Setup.R` holds the shared environment set-up.

No `renv.lock` is committed; the key packages are `Seurat`, `dplyr`, `ggplot2` and the helper package [`r-utility-functions`](https://github.com/Eomesodermin/r-utility-functions).

## Data

The raw and processed data are not stored in this repository. Download the data from the source above into `data/` (git-ignored) before running the scripts; processed objects are regenerated by the numbered scripts.
